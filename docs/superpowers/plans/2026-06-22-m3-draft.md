# Harry Draft — M3 Playable Draft Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the draft playable end-to-end — from the menu, pick 5 wizards across deterministic 5-card screens with fluid animations, then land on a team screen showing the squad and its active synergies.

**Architecture:** A pure `draftSession` engine helper rolls the shown candidates into DraftedWizards and advances picks deterministically from the run seed (engine logic stays out of React). A `useDraft` hook wraps it as React state. `DraftBoard`/`DraftSlot` render the cards with Framer pick/discard animations. A `/play` route hosts a small state machine (draft → team); `TeamScreen` shows the assembled squad + active synergies via the M1 synergy engine. The menu's Play button routes to `/play` with a generated seed.

**Tech Stack:** Next.js 16 (App Router), React, TypeScript strict, Tailwind v4, Framer Motion (incl. AnimatePresence), Lucide. Tests: Vitest + jsdom + @testing-library/react.

## Global Constraints

- TypeScript **strict** + `noUncheckedIndexedAccess`. Clean `tsc --noEmit`.
- **Engine purity preserved:** the new `draftSession` helper in `game/engine/` must be pure (injected `Rng`, no React/DOM/Math.random/Date). React state lives only in `hooks/` and `components/`.
- **Determinism:** the entire draft is reproducible from a single seed string. Same seed → same 5 screens, same candidate stats/spells, same order. Use `createRng(seed).fork(draftRngChannel)` (channel constant already exported from `game/engine/run.ts`) as the draft RNG root so draft RNG stays independent of combat RNG.
- Team size 5; each screen shows 5 cards; max 1 Tier-1 per screen; guaranteed Tier≤2 per screen; pity (all from M1 `generateScreen`). Picked card kept; the other 4 discarded and removed from the pool (M1 `commitPick`).
- Each shown candidate is displayed as a fully-rolled `DraftedWizard` (stats + spell visible before picking).
- Reuse M2 components: `WizardCard`, `GlowPanel`, `Button`, `houseTheme`, `cn`. Reuse M1 engine: `createDraftPool`, `generateScreen`, `commitPick`, `draftWizard`, `detectSynergies`. Do NOT duplicate their logic.

```ts
const ALPHABET = 'abcdefghijklmnopqrstuvwxyz0123456789'

export function randomSeed(): string {
  let s = ''
  for (let i = 0; i < 8; i++) {
    s += ALPHABET[Math.floor(Math.random() * ALPHABET.length)]
  }
  return s
}

export function normalizeSeed(raw: string | null | undefined): string {
  const trimmed = (raw ?? '').trim()
  return trimmed.length > 0 ? trimmed : randomSeed()
}
```

## Task 2: Pure draftSession engine

**Files:**
- Create: `game/engine/draftSession.ts`
- Test: `tests/engine/draftSession.test.ts`

**Interfaces:**
- Consumes: `createRng` + `draftRngChannel` (from `./rng` and `./run`), `createDraftPool`/`generateScreen`/`commitPick` (`./draft`), `draftWizard` (`./statRoll`), types `DraftedWizard`, `Wizard`, `Tier`.
- Produces:
  - `interface DraftSession { seed: string; pool: Wizard[]; picks: DraftedWizard[]; current: DraftedWizard[]; screenIndex: number; done: boolean }`
  - `startDraft(seed: string): DraftSession` — builds the RNG root, pool, and the FIRST screen's rolled candidates. `picks: []`, `screenIndex: 0`, `done: false`.
  - `pickFrom(session: DraftSession, candidateIndex: number): DraftSession` — adds the chosen rolled candidate to `picks`, removes all shown wizards from the pool, advances `screenIndex`; if `picks.length === teamSize` sets `done: true` and `current: []`, else rolls the next screen's candidates into `current`. Pure: returns a NEW session, deterministic from the original seed + pick history.
  - Determinism contract: rolling candidates uses an RNG forked per screenIndex off the draft root so a later pick choice never changes earlier/other screens' rolled stats. The 5 candidates' rolled stats are stable for a given (seed, screenIndex).

**Design note for the implementer:** the candidates shown for a screen are produced by `generateScreen(screenRng, pool, pickedTiers, screenIndex)` (returns `Wizard[]`), then each is rolled via `draftWizard(rollRng, wizard)`. Derive `screenRng` and `rollRng` deterministically from the draft root forked by `screenIndex` (e.g. `root.fork(screenIndex*2+1)` for screen selection, `root.fork(screenIndex*2+2)` for rolling) so screens are independent and reproducible. `pickedTiers` = the tiers of `picks` so far (for pity). `pool` carries forward (picked screens removed).

Create `game/engine/draftSession.ts`:
```ts
import type { DraftedWizard, Tier, Wizard } from '@/types'
import { createRng } from './rng'
import { draftRngChannel } from './run'
import { createDraftPool, generateScreen, commitPick } from './draft'
import { draftWizard } from './statRoll'
import { BALANCE } from '@/data/constants'

export interface DraftSession {
  seed: string
  pool: Wizard[]
  picks: DraftedWizard[]
  current: DraftedWizard[]
  screenIndex: number
  done: boolean
}

function rollScreen(seed: string, pool: Wizard[], pickedTiers: Tier[], screenIndex: number): DraftedWizard[] {
  const root = createRng(seed).fork(draftRngChannel)
  const screenRng = root.fork(screenIndex * 2 + 1)
  const rollRng = root.fork(screenIndex * 2 + 2)
  const shown = generateScreen(screenRng, pool, pickedTiers, screenIndex)
  return shown.map((w) => draftWizard(rollRng, w))
}

export function startDraft(seed: string): DraftSession {
  const pool = createDraftPool()
  const current = rollScreen(seed, pool, [], 0)
  return { seed, pool, picks: [], current, screenIndex: 0, done: false }
}

export function pickFrom(session: DraftSession, candidateIndex: number): DraftSession {
  const chosen = session.current[candidateIndex]
  if (!chosen) throw new Error(`invalid candidate index ${candidateIndex}`)

  const shownWizards = session.current.map((c) => c.wizard)
  const nextPool = commitPick(session.pool, shownWizards, chosen.wizard.id)
  const picks = [...session.picks, chosen]
  const screenIndex = session.screenIndex + 1

  if (picks.length >= BALANCE.draft.teamSize) {
    return { ...session, pool: nextPool, picks, current: [], screenIndex, done: true }
  }
  const pickedTiers = picks.map((p) => p.wizard.tier)
  const current = rollScreen(session.seed, nextPool, pickedTiers, screenIndex)
  return { ...session, pool: nextPool, picks, current, screenIndex, done: false }
}
```

```ts
'use client'
import { useState, useCallback, useEffect } from 'react'
import type { DraftedWizard } from '@/types'
import { startDraft, pickFrom, type DraftSession } from '@/game/engine/draftSession'
import { BALANCE } from '@/data/constants'

export function useDraft(seed: string): {
  current: DraftedWizard[]
  picks: DraftedWizard[]
  screenIndex: number
  teamSize: number
  done: boolean
  pick: (candidateIndex: number) => void
} {
  const [session, setSession] = useState<DraftSession>(() => startDraft(seed))

  useEffect(() => {
    setSession(startDraft(seed))
  }, [seed])

  const pick = useCallback((candidateIndex: number) => {
    setSession((s) => (s.done ? s : pickFrom(s, candidateIndex)))
  }, [])

  return {
    current: session.current,
    picks: session.picks,
    screenIndex: session.screenIndex,
    teamSize: BALANCE.draft.teamSize,
    done: session.done,
    pick,
  }
}
```

```tsx
import { useEffect, useRef } from 'react'
import type { DraftedWizard } from '@/types'
import { useDraft } from '@/hooks/useDraft'

export function DraftScreen({ seed, onComplete }: { seed: string; onComplete: (team: DraftedWizard[]) => void }) {
  const { current, picks, teamSize, done, pick } = useDraft(seed)
  const fired = useRef(false)

  useEffect(() => {

      <h1 className="font-display text-3xl">Draft</h1>
      {!done && (
        <DraftBoard candidates={current} picked={picks.length} total={teamSize} onPick={pick} />
      )}
      <p className="text-[10px] text-white/30 uppercase tracking-widest">seed: {seed}</p>
    </main>
  )
}
```

Create `components/screens/PlayFlow.tsx`:
```tsx
'use client'
import { useState, useCallback } from 'react'
import type { DraftedWizard } from '@/types'
import { DraftScreen } from './DraftScreen'
import { TeamScreen } from './TeamScreen'
import { randomSeed } from '@/lib/seed'

export function PlayFlow({ seed }: { seed: string }) {
  const [activeSeed, setActiveSeed] = useState(seed)
  const [team, setTeam] = useState<DraftedWizard[] | null>(null)

  const handleComplete = useCallback((t: DraftedWizard[]) => setTeam(t), [])
  const handleRestart = useCallback(() => {
    setTeam(null)
    setActiveSeed(randomSeed())
  }, [])

  if (team) {
    return <TeamScreen team={team} onRestart={handleRestart} />
  }
  return <DraftScreen key={activeSeed} seed={activeSeed} onComplete={handleComplete} />
}
```
